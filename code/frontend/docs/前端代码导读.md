## 1. 30 秒理解整个前端

**CS2 虚拟选手股票交易模拟器**的前端：16 名选手（8 队各 2 人）各有股价，用户用信用点买卖、看持仓盈亏与流水，还有 AI 买卖建议。

技术栈只有三样官方方案——无 UI 组件库、无图表库、无状态管理库：

| 工具                 | 在这里负责什么                                       |
| -------------------- | ---------------------------------------------------- |
| Vue 3（`^3.5`）      | 组合式 API（`<script setup>`），数据变了界面自动更新 |
| Vue Router（`^5.3`） | URL ↔ 页面对应、登录拦截                             |
| Vite（`^8.2`）       | 开发服务器 + 打包 `dist/` 静态文件                   |

**铁律：前端不产生任何业务结论。** 价格、盈亏、AI 建议全由后端接口给；前端只"取数 → 摆界面 → 转请求"，自己的计算只为体验（如"约需金额"预估）。

界面两层：

- `App.vue` 外壳，同一文件两套形态：桌面 = 左侧栏（纯导航 + 深浅色开关）；移动（≤960px）= 顶栏（下滑收起）+ 底部 4 Tab + 四页横向滑动画廊。`/auth` 不套外壳、全屏渲染；
- `src/views/` 8 个文件 = 7 页（市场/详情/赛程/持仓/流水/我的/登录）+ 404 兜底。

账号是**真鉴权**（第 7 轮起）：令牌由后端签发，余额持仓按账号隔离；"访客进入" = 故意不带令牌、用后端共用的演示账户，不是伪造登录（见 4.3）。

## 3. 分层：为什么代码要这么拆

只允许"上层调下层"，反过来不行：

```text
index.html（内联主题脚本）→ main.ts → App.vue 外壳
   └── views/（7 页 + 404）
         ├── components/（业务件 + ui/ 底座）      ← 复用小块
         ├── composables/（useAuth…useGlassGlow）  ← 跨页共享状态
         ├── core/（schedule/tradingStatus/tabPager）← 纯函数业务口径
         └── api/：index → cache → token → client  ← 所有 HTTP；mock/ 兜底
```

不是空话，两次真实验证：localStorage 假登录换真鉴权（`74f7193`），只动了 `api/`、`useAuth.ts`、守卫，数据页一行没改；停牌规则调整只改 `core/tradingStatus.ts`，三页口径自动一致。

## 4. 数据的三次旅程（跟着读代码最省力）

### 4.1 打开市场页

```text
① 访问 /（未登录会被守卫送去 /auth，见 4.3）
② router 匹配 MarketView（静态 import，首屏必带）→ 外壳的 <RouterView>（桌面）/ 画廊（移动）渲染它
③ onMounted(load)：
   loading=true → 6 张卡骨架屏 + useSlowHint（超 4 秒提示"唤醒中"）
   checkBackendHealth() → GET /api/health → 侧栏圆点
   api.listPlayers() → cached('players', 30s)：
     有缓存 → 秒回；同 key 在飞行 → 合并共用
     没有 → client.ts fetch（自动带 Authorization；GET 502/503/504 重试一次）
     成功 → 存缓存返回 PlayerSummary[]；失败 → 抛中文 ApiError
   成功 → v-for 画 16 名选手；失败 → ErrorState + 重试；finally 撤骨架
④ 搜索词变 → computed(filtered) 重算，不发请求
⑤ 悬停卡片 → 预取该选手 AI 建议；离开再回来 → useMarketState 恢复状态
```

关键点：只有 `.value` 被重新赋值的 `ref` 会让界面自动更新——Vue 响应式的核心。

### 4.2 详情页点"买入"

```text
① TradePanel 本地校验：正整数、持仓不超 50 股（契约 §4.7；后端另有单笔 ≤1000 兜底）；
   "最大"= min(余额÷现价, 50−已持有)；金额 ≥30% 余额 → 先亮黄色大额预警；停牌直接拦截
② api.buy → POST /api/trades/buy；成功后 api 内部先 invalidateCache() 整库清缓存
③ 成功 → 绿色横幅显示后端中文 message + emit('traded')（子不直接改父数据）
④ 父页收到 → loadCore(silent=true) 静默重拉详情/价格/持仓 + loadAnalysis() 再问 AI
   + refreshAccount() 更新共享余额（"最大可买"、/me 跟着变）
⑤ 失败（余额/持仓/上限/停牌）→ 红色横幅显示后端 message，输入不清空
   —— 绝不自动重试：重试 = 第二笔真实交易
```

### 4.3 登录 / 访客 / 换号（真鉴权，答辩常问）

```text
① 输口令 → api.login → POST /api/auth/login → 后端校验散列，签发 token
② useAuth.adopt()：先 invalidateCache() 清掉上一身份（或访客）的缓存
   → setToken：勾"记住我"进 localStorage，否则只进 sessionStorage（本标签页）
③ 跳回守卫存下的 ?redirect= 原页面；此后所有请求由 client.ts 自动带 Authorization
④ 刷新/重开：beforeEach 先 await bootstrap()（拿 token 问 GET /api/auth/me 恢复身份，
   401 才清会话）——顺序不能反，否则刷新第一屏被误判未登录、闪回登录页
⑤ 三种身份：private（私人账户，数据隔离）/ public_demo（"访客逛逛"= 故意不带令牌）/ anonymous
⑥ 退出/删号：先调后端撤销，**成功才** forgetSession()（清令牌+清缓存+重置界面）；
   删号口令错了绝不能清
```

血泪教训（`9d09f21`，11-26）：缓存按 URL 存、**不分用户**，此前只有买卖才清 → 换号会看到上一个人的持仓。修成"身份一切换必走 `forgetSession()`"。**新加任何改身份的入口都要记得调它。**

## 5. Vue / TS 写法小抄

| 写法 | 意思（本项目例子） |
| ---- | ---- |
| `.vue`（SFC） | 三段式：`<script setup>` 逻辑 / `<template>` 结构 / `<style scoped>` 只管本组件 |
| `ref(x)` / `reactive({...})` | 会变的值（脚本要 `.value`，模板自动解包）/ 一组字段（`AuthView` 表单） |
| `computed(fn)` | 由别的响应式数据推导的只读值（`TradePanel.maxQty`、`MarketView.filtered`） |
| `watch(src, cb)` | 值变时执行副作用（`App.vue` 按 `route.meta.title` 改浏览器标题） |
| `onMounted(fn)` | 渲染后执行——"进页面就加载数据"（每页 `onMounted(load)`） |
| `defineAsyncComponent` | 用到才下载组件代码（`MobileTabPager` 的四个页面） |
| `defineProps` / `withDefaults` | 父传子只读参数（`TeamLogo` 的 `team`、`UiModal`） |
| `defineEmits` / `emit('traded', res)` | 子通知父，父写 `@traded="…"`（交易回调） |
| `<slot />` | 内容口子（`EmptyState`、`UiModal`） |
| `v-if / v-for :key / v-model(.number) / @click / :class` | 条件、列表（`:key` 让 Vue 认行）、双向绑定、事件、表达式属性——满项目都是 |
| composable（`useXxx.ts`） | "状态+逻辑"抽成模块给多页共用（`useAuth`、`useTheme`） |
| 模块级 `ref` | ref 写在函数外：模块只执行一次，所有 import 者共享同一状态——本项目的"穷人版 Pinia" |
| `readonly(x)` | 只读导出，防别人乱改共享状态 |
| `<RouterView>` / `<RouterLink>` | 页面出口 / 不刷新的站内跳转（`<a>` 会整页重载，别用） |
| `import.meta.env.VITE_XXX` | 读构建时注入的环境变量（`api/client.ts`） |
| `Promise.all` / `?.` / `??` | 并发请求（详情页 loadCore+AI 并行）/ 取不到给默认值 |
| `matchMedia` / `localStorage` / `sessionStorage` | 问系统或视口条件（主题、≤960px）/ 持久化（主题偏好、令牌）/ 只活本标签页（市场状态、访客选择） |
| `interface` / `type` | 只描述形状、编译后消失（`api/types.ts`） |
| vitest `describe/it/expect` + `vi.mock` + `mount` | 用例 / 换假货模块 / jsdom 里渲染断言（`__tests__/`） |

| **预热 / 预取 / 意图预取** | 先连后端域名、空闲下分包、悬停卡片先问 AI——把等待挪到用户看不见的时候 |

| **设计令牌 / 材质层 / 内容层 / color-scheme** | CSS 变量两套主题（JSON 镜像同源）/ 只有壳和浮层能用玻璃（≤30%）/ 正文表格必须扁平 / 声明深浅色，否则原生控件白底 |
| **静默刷新（silent）** | 重新拉数据但不闪骨架不清空（交易成功后，`loadCore(true)`） |
| **请求令牌（requestToken）** | 防竞态自增号：响应回来号不对（用户已切走）就丢弃——别和"鉴权令牌"混 |
| **CORS 简单请求 / 预检** | GET 不带 `Content-Type` 免 `OPTIONS` 探路；所以 client 只给带 body 的请求加该头 |
| **三态 / 四态；涨红跌绿** | 加载(骨架)/空/错误(+正常)必须都画 / `--up` 红 `--down` 绿，国内习惯别按直觉反 |

**npm scripts**（在 `code/frontend` 下）：`dev`（5173 热更新）/ `build`（类型检查+打包）/ `preview` / `type-check` / `lint`（oxlint+ESLint 本地带 `--fix`，CI 只查不修）/ `format` / `test:unit`（Vitest，CI 同命令）。

## 9. 排错速查

| 现象 | 原因 → 处理 |
| ---- | ---- |
| "未配置后端地址…" | 没有 `.env.local` → `Copy-Item .env.example .env.local` 重启 |
| "无法连接后端服务…" | 后端没起/地址错/跨域 → 先 `curl http://127.0.0.1:8000/api/health` 再核对 |
| 侧栏圆点"未连接"但列表正常 | 徽标只看 `/api/health` 最近结果 → 点刷新会复检 |
| **换号后看到上一个人的数据** | 改身份的入口没走 `forgetSession()`（缓存按 URL 存不分用户）→ 所有换身份路径统一清（`9d09f21`） |
| 闲十几分钟后首访等近半分钟 | Render 冷启动 → 正常：GET 自动重试一次，超 4 秒有"唤醒中"提示 |
| 来回切页偶尔还是慢 | 缓存 TTL 过期或刚交易完全库失效 → 设计取舍：宁可重拉，不给旧数 |
| 刷新后闪回登录页 | 守卫没先 `await bootstrap()` 就放行判断 |
| 首屏"先深后浅"闪主题 | `index.html` 内联脚本与 `useTheme` 必须共用 `playerstock.theme.v1` 键 |
| 深色下原生控件白底 | 根元素缺 `color-scheme` 声明（`theme-guards.spec.ts` 防回归） |
| 访问 `/market` 白屏（线上） | 静态站 rewrite 掩盖了 404 → 靠路由的重定向+兜底解决，别删 |
| 买入成功但余额没变 | `api.buy` 已自动清缓存，再查父页 `@traded` 有没有 `refreshAccount()` |
| 数字和后端差一分 | 前端自己算了钱——违反铁律，金额一律后端给、前端只格式化 |
| 切选手时旧数据闪现 | 竞态 → 保留 `requestToken` 机制（`PlayerDetailView.loadCore`） |
| dev 端口不是 5173 | Vite 自动换端口 → 加进后端 CORS 白名单 |
