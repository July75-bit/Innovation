# 文档索引

本目录只放课程交付与答辩需要的文档；过程记录（每日站会、评审流水）在 `docs/retrospection/`、`docs/reviews/`，不作为交付材料。

| 目录 | 用途 | 先读 |
| --- | --- | --- |
| `requirements/` | 问题定义、功能/非功能需求、用户故事、线框 | `problem_definition.md` |
| `software/` | 架构、接口契约、数据库、部署、UI 规范 | `architecture.md` |
| `algorithm/` | 定价模型、AI 提示词、回测 | `pricing_model.md` |
| `acceptance/` | 测试计划/报告、用户手册、证据索引 | `test_report.md` |
| `mgmt/` | 沟通 / 风险计划、里程碑、缺陷记录、要求对照 | `communication_mgmt_plan.md` |
| `slides/` | Slidev 答辩稿 + 讲稿 | `slides.md` |
| `presentation/` | 演示脚本、问答、彩排 | `demo-script.md` |

写作约定：

- 一份文档只回答一个问题；细节能链到代码/Issue 就不复制。
- 状态、数字只写当前实测值，并注明日期与口径。
- 过程性长文（每日记录、逐条评审流水）不放主目录，避免交付材料臃肿。
