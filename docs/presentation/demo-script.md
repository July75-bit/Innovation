## 1. 脚本（逐秒对齐）

| 时间 | 操作 | 话术（照着说） |
| --- | --- | --- |
| 0:00–0:15 | 打开市场页 `/` | "这是市场页，8 名 CS2 选手，价格和评分都是我们设定的**模拟数据**；红涨绿跌，右上角显示后端已连接、余额 5000 虚拟币。" |
| 0:15–0:35 | 点第一行 **ZywOo** 进详情 | "进详情页。上面是当前价和涨跌幅，下面是**价格历史折线图**——注意每一个点都有原因。" |
| 0:35–1:00 | 鼠标悬停折线图第 3–4 个点，展示 tooltip；再展开"价格变动明细" | "比如这一场，本轮得分 76.6，S 等于 −1.0，所以价格跌了 15%——**这不是随机数，是比赛表现算出来的**。" |
| 1:00–1:20 | 指 AI 建议卡 | "AI 给的是**建议**：持有、风险低、理由引用具体数值，还标了来源是规则兜底还是模型；底下这句免责声明是契约强制的——**AI 永远不会自动交易**。" |
| 1:20–1:45 | 数量填 **2** → 点**买入** | "买 2 股，成交价取**当前最新价**。看顶部余额：5000 → 4747.46，右下角持仓变成 2 股。"（等接口返回再念数字） |
| 1:45–2:00 | 点顶部**持仓** → 再点**交易记录** | "持仓页有均价、市值和浮动盈亏，都是后端算好的；交易记录按时间倒序，每笔带交易后余额——**钱和货是对得上的**。" |

> **收尾一句**（如果还有 5 秒）："2 分钟演示到这里，背后是 137 条自动化测试和 6 项线上验收。"

## 2. 备用路径（现场按需切换）

| 场景 | 换成这个 |
| --- | --- |
| 想展示错误处理（很加分） | 数量填 **999** 点买入 → 弹出"余额不足，当前余额…需要…"→ 说"错误信息由后端直出，前端不做映射表" |
| 想展示暂停交易 | 回市场页点 **sh1ro**（状态"暂停交易"）→ 按钮置灰 → 说"比赛中暂停交易是规则的一部分" |
| 想展示三态 | 断网/停后端 → 显示"无法连接后端服务 + 重试" → 说"失败态有兜底 UI，不白屏" |
| AI 挂了 | 直接说"正好演示降级"：卡片会标 `规则兜底（AI 暂不可用）`，交易照常可用 |

## 4. 失败预案（演练一次）

| 故障 | 应对（3 秒内切换） |
| --- | --- |
| 页面白屏 / 502 | 立刻切到**录屏**，说"线上免费实例在冷启动，这是同一套系统的录屏" |
| 接口 500 | 刷新一次；仍失败 → 切本地环境（提前开好） |
| 网络断 | 切录屏 + 本地兜底 |
| 时间超了 | 砍持仓页和流水，**保"看详情 + 买入"**（这两个最能说明机制） |
| 被老师打断提问 | 先回答问题，再问"需要我继续演示还是直接进入问答？" |
