## 1. 脚本（逐秒对齐）

| 时间 | 操作 | 话术（照着说） |

| 0:15–0:35 | 点第一行 **ZywOo** 进详情 | "进详情页。上面是当前价和涨跌幅，下面是**价格历史折线图**——注意每一个点都有原因。" |
| 0:35–1:00 | 鼠标悬停折线图第 3–4 个点，展示 tooltip；再展开"价格变动明细" | "比如这一场，本轮得分 76.6，S 等于 −1.0，所以价格跌了 15%——**这不是随机数，是比赛表现算出来的**。" |

## 2. 备用路径（现场按需切换）

| 场景 | 换成这个 |
| --- | --- |
| 想展示错误处理（很加分） | 数量填 **999** 点买入 → 弹出"余额不足，当前余额…需要…"→ 说"错误信息由后端直出，前端不做映射表" |

## 4. 失败预案（演练一次）

| 故障 | 应对（3 秒内切换） |
| --- | --- |
| 页面白屏 / 502 | 立刻切到**录屏**，说"线上免费实例在冷启动，这是同一套系统的录屏" |
| 接口 500 | 刷新一次；仍失败 → 切本地环境（提前开好） |
| 网络断 | 切录屏 + 本地兜底 |
| 时间超了 | 砍持仓页和流水，**保"看详情 + 买入"**（这两个最能说明机制） |
| 被老师打断提问 | 先回答问题，再问"需要我继续演示还是直接进入问答？" |
