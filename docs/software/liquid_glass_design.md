# 液态玻璃材质层（历史规范）

> 状态：**已被纸感模式取代**（2026-11-18）。当前基线是暖纸色、实色卡片、细边、去玻璃，见 @@ui_design_system.md@@ 与 @@design_tokens.md@@。

## 为什么放弃

- 玻璃在纯色背景上几乎看不出效果，实测桌面侧栏开/关 blur 的像素差接近 0；
- 内容层（表格、长文、交易面板）需要可读性，玻璃降低对比度；
- 维护成本高：需要 @@supports@@ / 降低透明度 / 手动开关三条降级路径。

## 保留的价值

- 移动顶栏、弹窗、下拉这些「浮层」仍可用玻璃；纸感模式下已改为实色 + 细边。
- 历史实测数据（玻璃面积桌面 18.13% / 移动 8.25%、玻璃文字最低对比度 8.55:1）留在 git 历史里，需要回滚时查旧提交。
