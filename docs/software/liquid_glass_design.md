> 落地提交：`src/assets/liquid-glass.css`（令牌 + 材质类 + 降级）、`App.vue`（侧栏/顶栏）、
> `components/ui/UiModal.vue`、`components/DeleteAccountDialog.vue`、`components/PriceChart.vue`（tooltip）、
> `views/UiKitView.vue`（/ui-kit 材质展厅）
> 证据：`docs/acceptance/evidence/56~65-liquid-glass-*.png`
> 验收实测：2026-11-14 16:40（Edge 157 headless + CDP 量算，不是"目测"）

## 1. 改版诊断（最多 8 条，全部来自实测）

| # | 问题 | 违反的原则 | 证据 |
| --- | --- | --- | --- |
| 1 | 全站**没有材质分层**：导航壳、内容卡、表格、弹层都是同一种实色表面，层级只靠间距 | 产品化（层级不清） | `tokens.css` 只有 1 档 surface |

| 8 | 浅色模式完全没有材质定义（只有深色一套），无法交付"明暗双主题的玻璃" | 规范完整性 | §3.2 |

## 2. 分层方案（哪些扁平、哪些玻璃、为什么）

**判定规则（一句话）**：会**盖住其他内容**的"壳/浮层"才是材质层；承载**阅读与输入**的一块都不许用玻璃。

| 区域 | 层级 | 用什么 | 理由 |
| --- | --- | --- | --- |
| 桌面侧栏壳（品牌/导航/账户卡/合规） | 材质层 | **玻璃**（`glass--nav`，tint 0.66） | 常驻导航壳；内部账户卡/合规文本仍是**实色**（玻璃 + 实色，两层，不违规） |
| 移动端顶栏（品牌/余额/菜单） | 材质层 | **玻璃**（tint 0.66，移动端 blur 18px） | 内容从下面滚过，模糊有真实可糊的东西——液态玻璃最成立的位置（证据 `58`） |
| 移动端抽屉 | 内容层 | **实色 sheet**（圆角 24、轻投影） | ①占屏 78vw×100dvh，玻璃面积直接破 30% 配额；②导航+账户+合规是文字密集区 |
| 模态框 / 删除账号确认（桌面 ≥601px） | 材质层 | **玻璃面板**（tint 0.74，圆角 20，极轻投影） | 浮层，靠材质与阴影表达"浮在页面之上" |
| 模态框（≤600px） | 内容层 | **实色底部 sheet**（圆角 24 上沿） | 手机上弹窗接近全屏：玻璃面积会到 60%+，且里面是表单 |
| 图表 tooltip | 材质层 | **玻璃浮层**（tint 0.74，圆角 20） | 小块浮层，压在折线上（证据 `57`） |
| 底部工具条 / 悬浮操作条 | 材质层 | **玻璃**（`glass--control`，tint 0.62，圆角 12） | 悬浮控件；按钮本身仍是实色 |
| 市场卡片、表格、表单、AI 分析正文、持仓/流水/赛程 | 内容层 | **扁平**：实色 + 1px 边框、无阴影、无模糊 | 高对比、高可读；表格/长文禁止玻璃 |
| 遮罩（scrim） | 非玻璃 | 纯色压暗（0.66），**不再做 blur** | 避免"玻璃叠玻璃"：模糊只由玻璃层承担 |

**同屏玻璃配额账（实测）**

| 屏幕 | 玻璃块 | 可见玻璃面积 | 结论 |
| --- | --- | ---: | --- |
| 桌面市场页（1280×900） | 侧栏 232×900 | **18.13%** | ✅ ≤30% |
| 桌面详情页 + 图表 tooltip | 侧栏 + tooltip | **19.97%** | ✅ ≤30% |
| 移动市场页（375×667，滚动中） | 仅顶栏 375×55 | **8.25%** | ✅ ≤30% |
| 移动抽屉打开 | 抽屉=实色，仅顶栏玻璃 | **8.25%** | ✅ ≤30% |
| 桌面弹窗打开 | 弹窗 400×263 单独计 | **9.10%**（背景玻璃被遮罩压暗，按规则不计） | ✅ ≤30% |
| `/ui-kit` 材质展厅 | 同时展示 5 块材质 | 38–44% | ⚠️ **展厅页豁免**（不在主导航，用于设计验收；页面自带配额读数） |
| 降级模式（`no-backdrop-filter`） | 全部回退实色 | **0%** | ✅ |

## 3. 设计 Token

### 3.1 玻璃（深色默认，`liquid-glass.css`）

```css
--glass-blur: 22px;            /* 规格 18–28；≤600px 降为 18px 省 GPU */
--glass-saturate: 180%;        /* 规格 160–200% */
--glass-tint-nav: rgba(18,20,26,0.66);    /* 导航壳 scrim */
--glass-tint-panel: rgba(18,20,26,0.74);  /* 模态/浮层 scrim（文字更多，压得更实） */
--glass-tint-control: rgba(24,27,34,0.62);/* 工具条/悬浮控件 scrim */
--glass-border: rgba(255,255,255,0.16);   /* 1px 描边 */
--glass-highlight: rgba(255,255,255,0.14);/* 顶部 1px 内高光（inset） */
--glass-hover-glow: rgba(255,255,255,0.08);/* hover 柔和斜向高光 */
--glass-shadow: 0 16px 40px rgba(0,0,0,0.38); /* 仅浮层 */
--glass-solid: #171a21;        /* 降级实色 */
```

### 3.2 浅色玻璃（作用域 `.theme-light`，不全局切换）

```css
--glass-tint-nav: rgba(255,255,255,0.62);
--glass-tint-panel: rgba(255,255,255,0.72);
--glass-tint-control: rgba(255,255,255,0.58);
--glass-border: rgba(255,255,255,0.78);
--glass-highlight: rgba(255,255,255,0.90);
--glass-shadow: 0 16px 40px rgba(16,24,40,0.16);
--glass-solid: #ffffff;
/* 同时把内容语义令牌翻成浅色（canvas #e9ecf2 / surface #fff / text #15181e / border #d7dbe3） */
```

> 业务页默认深色；浅色玻璃在 `/ui-kit` 展厅内用 `.theme-light` 作用域演示（证据 `61` 底部），
> 全站切浅色需要逐页回归，本轮**没有**做全局主题开关（如实说明）。

### 3.3 颜色 / 字体 / 间距（沿用既有 `tokens.css`，不改内容层）

- 颜色：中性 9 阶 + 1 主色（品牌红 `#e5484d`，实心按钮 `#c23438`）+ 语义色（成功绿/警告琥珀/错误红）；玻璃不是新颜色，只是"中性色 + 透明度 + 模糊"。
- 字体：H1 28 / H2 22 / H3 18 / **正文 16** / 辅助 14 / 最小 13；行高 1.35（标题）/1.6（正文）/1.5（辅助）。
- 间距：8pt 体系 4/8/12/16/24/32/48/64；控件高 36/40/44；图标 16/20/24。

### 3.4 圆角（按层两套，互不混用）

| 层 | 取值 | 用途 |
| --- | --- | --- |
| 内容层 | **4 / 6 / 8** | 标签 / 按钮输入框 / 卡片表格 |
| 材质层-控件 | **12** | 悬浮工具条、胶囊控件 |
| 材质层-浮层 | **20** | 模态框、tooltip、popover |
| 材质层-大面板 | **24** | 移动端 sheet/抽屉（实色） |

### 3.5 阴影与边框

- 内容卡：`--shadow-none` + 1px `--color-border`。
- 玻璃壳：只有 `inset 0 1px 0 --glass-highlight`（1px 内高光，是材质边界，不是投影）。
- 浮层：内高光 + `--glass-shadow`（唯一的"阴影"用途 = 表达悬浮）。

### 3.6 Fallback 三件套

1. `@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))` → 实色底 `--glass-solid`，保留圆角/描边；
2. `@media (prefers-reduced-transparency: reduce)` → 同样回退实色，并**关掉 hover 半透明高光**（Edge 157 实测可触发，见 `65`）；
3. `html.no-backdrop-filter` → 手动开关（`/ui-kit` 里的「模拟降级」按钮），用于现场演示降级效果（证据 `62`，实测玻璃面积 0%）。
4. `@media (hover:hover) and (pointer:fine) and (prefers-reduced-motion: no-preference)` 才启用动态高光 → 移动端与"减少动效"用户自动关闭（实测 hover 后 `::after` opacity 仍为 0）。

## 6. 可运行代码

**新增** `code/frontend/src/assets/liquid-glass.css`（约 240 行，全部令牌 + 材质类 + 降级，带分层注释），
由 `src/assets/main.css` 在末尾 `@import` 引入；业务页**只需加类名**：

```html
<!-- 导航壳（桌面） -->
<aside class="sidebar glass glass--nav"> … </aside>

<!-- 玻璃弹窗 -->
<section class="ui-modal glass glass--panel ui-modal--md"> … </section>

<!-- 悬浮工具条 -->
<div class="glass glass--control glass--interactive"> … </div>
```

```css
/* 核心实现（节选，完整见文件） */
.glass {
  background-color: var(--glass-tint-panel);            /* scrim：保证文字对比度 */
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate));
  backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate));
  border: 1px solid var(--glass-border);
  box-shadow: inset 0 1px 0 var(--glass-highlight);      /* 只有 1px 内高光 */
}
.glass--panel {
  border-radius: var(--glass-radius-panel);              /* 20 */
  box-shadow: inset 0 1px 0 var(--glass-highlight), var(--glass-shadow);
}
@media (hover: hover) and (pointer: fine) and (prefers-reduced-motion: no-preference) {
  .glass--interactive:hover::after { opacity: 1; }       /* 移动端/减少动效=不启用 */
}
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .glass { background-color: var(--glass-solid); backdrop-filter: none; }
}
```

**改用到的现有组件**：`App.vue`（侧栏/顶栏）、`UiModal.vue`、`DeleteAccountDialog.vue`、
`PriceChart.vue`（tooltip）、`UiKitView.vue`（`/ui-kit` 增加「液态玻璃」展厅：导航壳/工具条/Popover/浅色玻璃/降级开关/配额读数）。

**已知限制（如实记录）**

1. `/ui-kit` 材质展厅同屏 5 块玻璃（38–44%），是"组件展厅"性质，**不计入业务页配额**；页面上已写明并显示实测读数。
2. 全网只有深色主题上线；浅色玻璃以 `.theme-light` 作用域演示（`/ui-kit`），全局主题开关未做——切浅色需要逐页回归对比度。
3. 玻璃的"液态流动感"只做 hover 轻微斜向高光，没有跟随鼠标的位移/折射（规格禁止持续动态高光；性能也不允许）。
4. 遮罩层去掉了 blur，所以**极端低性能设备**上也不会出现"两层模糊"。
