## 1. 改版诊断（v1 的问题，最多 8 条）

| # | 问题 | 违反的原则 |
| --- | --- | --- |
| 1 | 页面背景用「径向渐变 + 两层 40px 网格纹理」，像电竞壁纸而不是产品 | 扁平化（禁止渐变/装饰纹理） |
| 2 | 状态点/按钮带 `box-shadow: 0 0 10px` 发光，抽屉/弹窗用 24px 大投影 | 扁平化（禁止重阴影/发光） |
| 3 | 圆角混用 8 / 12 / 16 / **999（胶囊）** 四档 | 圆角统一（只用 4/6/8） |
| 4 | 正文 14px、辅助 11–12px，低于可读性下限 | 可读性（正文 ≥16、辅助 ≥12–13） |
| 5 | 底色 `#0b0c0e` 接近纯黑，长时间阅读刺眼且层级靠"更黑"表达 | 禁止大面积纯黑 |
| 6 | AI 卡把来源行/JSON/四格数字/置信度 48% 全摊开，一屏 9 块内容 | 简洁化（一屏一主任务） |
| 7 | 导航选中态是整块主色红，与「买入」主 CTA 抢视觉焦点 | 产品化（视觉焦点唯一） |
| 8 | 简报摘要意外显示模型 JSON（`{"action": "HOLD", ...}`） | 产品化（文案必须是人话） |

> 第 6、8 条已在前序改版修掉（AI 卡三层折叠 / 后端 + 前端双重清洗），本轮修 1–5、7。

## 2. 信息架构

只保留 **3 层**（全局导航 → 页面 → 页面内区块），不做多级菜单：

```
全局侧栏（232px）
├─ 品牌
├─ 市场 / 赛程 / 持仓 / 交易记录        ← 一级：4 个目的地
├─ 账户卡（余额 / 总资产 / 总收益）
└─ 服务状态 + 合规声明
页面
├─ 市场页：今日简报 → 赛程条 → 搜索/筛选/排序 → 选手卡片网格（主 CTA=点卡片）
├─ 详情页：行情头（价格大字）→ 价格历史 → AI 结论（主 CTA=买入）→ 交易面板
├─ 持仓页 / 流水页：只读列表（主任务=核对）
└─ 登录页：表单（主 CTA=进入市场 / 注册）
```

**主次操作**：每页只有一个主操作——市场页「点选手」、详情页「买入」、登录页「进入市场」。
其他动作（刷新、重新分析、采纳建议、退出）一律次级样式（描边/ghost）。

## 8. 已知取舍

- **深色主题**：金融/电竞场景常用深色；已把最暗提到 `#12141a`（非纯黑），并保证 AA 对比度。
- **涨红跌绿**：遵循国内证券习惯（与欧美相反），已在 `main.css` 注释说明。
- **主题**：已有「自动（跟随系统）/ 浅色 / 深色」三档（`useTheme`，默认自动），全站令牌一套两值，组件不写模式判断。
- **材质层**：2026-11-18 起从「液态玻璃」降级为**纸感实色表面 + 1px 细边**（`.glass` 类名保留以便回滚），
  历史规范与实测见 [`liquid_glass_design.md`](./liquid_glass_design.md)。

## 9. 审美参考与 P1 对齐（2026-11-14）

参考对象：KPL 小助手（kplll.online）—— 浅色数据台，白卡 + 1px #f0f0f0 + 圆角 8 + 零阴影，
靠留白（卡片 24、表格行 71）与灰度分层（#333/#666/#999）建立秩序，全站只有蓝/绿两个强调色。

**我们借了什么**（P1，见 `ui_components.md §7.7`）：更大的表格行高与卡片留白、淡主色底 pill 选中态、
标题降噪、更轻的浅色边框、内容卡不再位移/加阴影、可点文字统一文字档主色。
**我们没借什么**：10–12px 小字与 #999 浅灰（不达 AA）、蓝色主色（品牌红已定）。
（当时"全站去玻璃"被视为冲突；2026-11-18 用户明确要"克制感"，已改为纸感、去掉玻璃。）

## 10. 登录页（/auth）的双模式修正（2026-11-14）

**问题**：登录页是主题改造前写的"深色主视觉页"——大量颜色硬编码为浅色（`#d6d8dd` / `#dfe1e6` / `#a9adb6`）、
面板固定深底 `rgba(18,20,24,.78)`。加了浅色主题后，`--text/--muted` 翻转成深色，于是出现
"白底白字 / 深底深字"的混合态，**浅色下完全不可读**（用户截图确认）。

**修法**（不重做布局，只做令牌化 + 去装饰）：
1. 页面背景改为 `--color-canvas` 纯色；**删掉装饰背景图与遮罩层**（原 `.veil` 是纯色，图片其实一直被盖住）；
2. 左侧文案全部改用 `--text / --muted / --faint`；去掉文字 `text-shadow`（重阴影）；
3. 表单面板改为内容层：`--color-surface` 实色 + 1px `--color-border` + 圆角 8，**去掉 backdrop-blur 与发光阴影**；
4. 输入框/标签/提示/错误/密码强度条/链接全部换成语义令牌，输入框与主按钮 44px；
5. 浅/深两套令牌自动适配，不再有"只在某一模式成立"的硬编码色。

**验证**：1440/1280/375 × 深/浅 共 6 组，自动对比度审计**违规 0**、无横向溢出；证据 `91~94`。

**登录页自带主题切换**（2026-11-14 补）：`/auth` 不套外壳，所以页面右上角单独放了一个主题按钮，
与全站共用 `useTheme` 的「自动 → 浅色 → 深色」三档循环（`cycleTheme`），
`aria-label` 说明当前偏好与下一个模式；点击即时切换整页令牌，偏好写入 localStorage 与全站一致。
按钮 44px 点击区、桌面显示图标+文字、窄屏只留图标（文字进 aria-label）。证据 `95~97`。

## 11. 纸感模式（2026-11-18，当前基线）

**背景**：用户反馈「界面太繁复，一打开就是几十项内容涌过来，没有读的欲望」，要求**可读、低密度、简洁、从容、秩序、克制**。
经确认采用三条原则：**先试点两页 → 纸感（去玻璃）→ 市场页一屏 6 张卡**。

### 11.1 设计语言
- **纸感**：暖中性底色 + 纯白卡片 + 1px 细边；不用模糊、高光、投影、渐变、悬停位移。
- **排版优先**：正文行高 1.6→**1.7**；标题 24/20/16；数字用 tabular-nums；辅助信息降到 13px 的灰。
- **层级靠留白**：区块间距 24→32/48；侧栏 232→**220**；内容最大宽 1280→**1040**（阅读行宽收窄）。
- **色彩克制**：主色只用于主操作与涨跌；选中态从「彩色底 pill」改成**深色文字 + 2px 左竖线**。

### 11.2 令牌变化（CSS 与 JSON 同步，spec 守卫）
| Token | 深色 | 浅色 | 说明 |
| --- | --- | --- | --- |
| `--color-canvas` | `#141310` | `#f6f4ef` | 暖纸底 |
| `--color-surface` | `#1b1a17` | `#ffffff` | 卡片 |
| `--color-border` | `#2e2b25` | `#e6e2d9` | 1px 细边 |
| `--line-height-body` | `1.7` | 同 | 正文更松 |
| `--layout-sidebar-width` / `--layout-content-max` | `220 / 1040` | 同 | 收窄阅读区 |

玻璃令牌不再是"半透明 + 模糊"：`liquid-glass.css` 末尾统一覆盖成实色表面（类名与降级逻辑保留，可一键回滚）。

### 11.6 顶部信息条：图标替代文字（2026-11-18）

市场页顶部原先是「一句话 + 『AI 生成』+ 『展开要点』按钮」和一行
「第 18 轮 · FaZe Clan vs NAVI 比赛中，4 人暂停交易　看赛程」——按钮像个小方框、句子太长。

- 简报操作：文字按钮 → **星标图标（来源，悬停/读屏给出「AI 生成简报 / 简化模式」）+ 箭头图标（展开/收起，`aria-expanded`）**；
- 展开后的三条要点：每行「小图标 + 短标题 + 一行值」（`最该看 / 低价区 / 停牌`），轮次与对阵不再重复（比赛行已有）；摘要行用 `em` 限宽，宽屏一行放得下；
- 比赛行：长句 → **轮次 + 两队队标与队名 + 圈形暂停图标「N 人」+ 日历图标（跳赛程）**；
- 全部图标带 `aria-label` / `sr-only` 文案，点击区 ≥40px；移动端整行仍是一行、无横向溢出。

### 11.7 重点数字条：用大小与颜色取代句子（2026-11-18）

  - 涨跌值 24px/600，**涨红跌绿**（`+13.96%` 用 `--up-text`，负值用 `--down`）

### 11.9 动效：短、只动 opacity/transform、尊重减少动效（2026-11-18）

目标：切换页面、开菜单、进下一层时有"丝滑"反馈，但不抢注意力。

| 场景 | 做法 | 时长 |
| --- | --- | --- |
| 路由切换 | 旧页淡出 → 新页淡入 + 上移 8px（`mode="out-in"`，不重叠） | 120ms + 240ms |
| 移动端抽屉 | `translateX(-105%) → 0`，`cubic-bezier(.22,1,.36,1)` | 260ms |
| 抽屉遮罩 | opacity 0 → 0.55（`fade` 过渡） | 200ms |
| 弹窗 | 遮罩淡入 + 面板上移 10px、scale .985 → 1 | 180–220ms |
| 下拉弹层 | opacity + `translateY(-4px)`、scale .99 → 1，原点在顶部 | 140–160ms |
| 市场卡片 | opacity + 上浮 4px，20ms 阶梯（最多 120ms 延迟） | 300ms |
| 登录页 | 淡入 + 上移 6px（它不走 RouterView 过渡） | 240ms |
| hover / 选中 | 颜色/背景/边框过渡 | 120–160ms |

- 全部只用 `opacity` / `transform`，不触发布局；`mode="out-in"` 避免两页同时在场。
- **`prefers-reduced-motion: reduce` 全部退化为瞬时**：路由/遮罩/弹窗/下拉/卡片/抽屉/登录页均不播动画。

验证（CDP 逐帧采样，非目测）：路由 leave 透明度 1→0.017（8 帧）、enter 位移 7.64px→0.75px；
抽屉中段 `translateX(-160px)` + 遮罩 opacity 0.07；弹窗遮罩 0→0.26→0.76→0.997；下拉 0.88→1；
开启减少动效后 `document.getAnimations()` 为空、抽屉 `transition-duration: 0s`。

### 11.10 专业化打磨：品牌、元信息与细节（2026-11-18）

目标：让作品从"能用的课程 demo"更像"正经产品"。

- **品牌资产**：生成红色圆角方块 + 白色 P 的 SVG/ICO/PNG 图标（`favicon.svg`/`favicon.ico`/`icon-192/512.png`/`apple-touch-icon.png`），
  加 `manifest.webmanifest`（可安装为 PWA，主题色/背景色与纸感一致）。
- **站点元信息**（`index.html`）：`description`、`og:title/description/locale`、双 `theme-color`（浅 `#f6f4ef`/深 `#141310`）；
  手切主题时 `useTheme` 会同步更新 `theme-color`，地址栏颜色跟页面一致。
- **404 页**：兜底路由从"静默重定向首页"改为真正的 404 页面（`NotFoundView.vue`，public + 标题「页面不存在」+ 回到市场）。
- **数字与时间口径**：金额统一千分位两位小数（`4,748.00`）、日期/时钟统一 24 小时制 `zh-CN`（`dateTime`/`clockTime`），
  表格数字用 `tabular-nums`，不会左右跳。
- **换页滚动**：普通跳转回顶部，浏览器前进/后退恢复原位置（`router.scrollBehavior`）。
- **可访问性**：新增「跳到主要内容」skip link（键盘第一个 Tab）+ `main#main` 地标。
- **加载骨架**：持仓/流水加载时按版式占位（`aria-busy`，减少动效时停跳）。
- 细节：`::selection` 品牌淡色、滚动条细化、`-webkit-font-smoothing`（原有）。

证据：`119~122-pro-*.png`。
