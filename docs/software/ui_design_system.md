# UI 设计规范 v2（扁平化 · 产品化）

> **对象**：PlayerStock 虚拟选手股交易模拟（课程作品，答辩演示为主）

> **实施提交**：`code/frontend/src/assets/main.css`（令牌）+ `App.vue` / `MarketView.vue` /

## 1. 改版诊断（v1 的问题，最多 8 条）

| # | 问题 | 违反的原则 |
| --- | --- | --- |
| 1 | 页面背景用「径向渐变 + 两层 40px 网格纹理」，像电竞壁纸而不是产品 | 扁平化（禁止渐变/装饰纹理） |
| 2 | 状态点/按钮带 `box-shadow: 0 0 10px` 发光，抽屉/弹窗用 24px 大投影 | 扁平化（禁止重阴影/发光） |
| 3 | 圆角混用 8 / 12 / 16 / **999（胶囊）** 四档 | 圆角统一（只用 4/6/8） |
| 4 | 正文 14px、辅助 11–12px，低于可读性下限 | 可读性（正文 ≥16、辅助 ≥12–13） |
| 5 | 底色 `#0b0c0e` 接近纯黑，长时间阅读刺眼且层级靠"更黑"表达 | 禁止大面积纯黑 |
| 6 | AI 卡把来源行/JSON/四格数字/置信度 48% 全摊开，一屏 9 块内容 | 简洁化（一屏一主任务） |
| 7 | 导航选中态是整块主色红，与「买入」主 CTA 抢视觉焦点 | 产品化（视觉焦点唯一） |
| 8 | 简报摘要意外显示模型 JSON（`{"action": "HOLD", ...}`） | 产品化（文案必须是人话） |

> 第 6、8 条已在前序改版修掉（AI 卡三层折叠 / 后端 + 前端双重清洗），本轮修 1–5、7。

## 2. 信息架构

只保留 **3 层**（全局导航 → 页面 → 页面内区块），不做多级菜单：

```
全局侧栏（232px）
├─ 品牌
├─ 市场 / 赛程 / 持仓 / 交易记录        ← 一级：4 个目的地
├─ 账户卡（余额 / 总资产 / 总收益）
└─ 服务状态 + 合规声明
页面
├─ 市场页：今日简报 → 赛程条 → 搜索/筛选/排序 → 选手卡片网格（主 CTA=点卡片）
├─ 详情页：行情头（价格大字）→ 价格历史 → AI 结论（主 CTA=买入）→ 交易面板
├─ 持仓页 / 流水页：只读列表（主任务=核对）
└─ 登录页：表单（主 CTA=进入市场 / 注册）
```

**主次操作**：每页只有一个主操作——市场页「点选手」、详情页「买入」、登录页「进入市场」。
其他动作（刷新、重新分析、采纳建议、退出）一律次级样式（描边/ghost）。

## 3. 设计 Token（`src/assets/main.css`）

| 类别 | 变量 | 值 |
| --- | --- | --- |
| 底色 | `--bg` / `--surface` / `--surface-2` / `--surface-3` | `#12141a` / `#181b22` / `#1f232b` / `#262b34` |
| 文字 | `--text` / `--muted` / `--faint` | `#e9eaee` / `#b6bac4` / `#8f949f` |
| 边框 | `--border` / `--border-strong` | `#2c313b` / `#3a404c` |
| 主色 | `--accent` / `--accent-hover` / `--accent-weak` | `#e5484d` / `#f05a5f` / `rgba(229,72,77,.14)` |
| 语义 | `--down`(成功/跌) / `--warn` / `--danger` | `#2fbf71` / `#d99427` / `#dc2626` |
| 间距 | `--space-1…8` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 圆角 | `--radius-xs/sm/md/lg` | **4 / 6 / 8 / 8**（`--radius-pill` 也映射为 6，不再有 999） |
| 字体 | `--fs-h1/h2/h3/body/aux/cap` | 28 / 22 / 18 / **16** / 14 / 13 |
| 行高 | `--lh` / `--lh-tight` | 1.6 / 1.35 |
| 控件高 | `--control-sm/md/lg` | 36 / 40 / 44 |
| 图标 | `--icon-sm/md/lg` | 16 / 20 / 24 |
| 阴影 | `--shadow-1` / `--shadow-2` | **none** / `0 1px 2px rgba(0,0,0,.3)`（仅弹层） |
| 布局 | `--max-width` / `--sidebar-width` | 1280 / 232 |

**层级表达**：一律用 `1px 边框 + 背景色差（bg→surface→surface-2→surface-3）`，
不使用渐变、发光、大投影；焦点态用 `outline: 2px solid var(--accent); offset 2px`。

## 5. 组件清单与状态

| 组件 | 默认 | 悬停 | 焦点 | 禁用 | 其他 |
| --- | --- | --- | --- | --- | --- |
| 主按钮（买入） | 主色实底 / 高 44 | 主色亮一档 | 2px 焦点环 | 降透明度、cursor default | 提交中显示「提交中…」 |
| 次按钮（刷新/重新分析/采纳） | 透明 + 1px 边框 | 边框提亮、文字变白 | 焦点环 | 降透明度 | — |
| 危险操作（删除账号） | 红描边 | 红底浅填充 | 焦点环 | 降透明度 | 必须二次确认 |
| 输入框（数量） | surface 底 + 1px 边框 | 边框提亮 | 焦点环 + 边框主色 | 变灰 | 校验失败：边框警告色 + 提示文案 |
| 选手卡片 | surface + 1px 边框 + 8px 圆角 | 边框提亮（不动阴影） | 焦点环 | — | 暂停：徽章变警告色 |
| 状态徽章 | 4px 圆角 + 语义浅底 | — | — | — | 附文字（不只靠颜色） |
| 表格/列表（持仓/流水） | 分割线 1px | 行悬停浅底 | 行内链接可聚焦 | — | 空态文案 + 操作引导 |
| 弹层（删除账号） | surface-2 + 1px 边框 + 唯一允许的轻投影 | — | 焦点入弹层 | 确认按钮禁用直到输入 | Esc 关闭 |

关键规则（可直接复制的片段）：

```css
/* 扁平卡片：1px 边框 + 背景差，不用阴影 */
.card { background: var(--surface); border: 1px solid var(--border); border-radius: var(--radius-md); }

/* 主按钮：唯一实色主色，44px 高 */
.btn-primary { height: var(--control-lg); background: var(--accent); color: #fff;
  border: 0; border-radius: var(--radius-sm); font-weight: 600; }
.btn-primary:hover:not(:disabled) { background: var(--accent-hover); }
.btn-primary:disabled { opacity: .55; cursor: default; }

/* 次级按钮 */
.btn-ghost { height: var(--control-md); background: transparent; color: var(--muted);
  border: 1px solid var(--border); border-radius: var(--radius-sm); }
.btn-ghost:hover:not(:disabled) { color: var(--text); border-color: var(--border-strong); }

/* 键盘焦点 */
:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; border-radius: var(--radius-sm); }
```

## 8. 已知取舍

- **深色主题**：金融/电竞场景常用深色；已把最暗提到 `#12141a`（非纯黑），并保证 AA 对比度。
- **涨红跌绿**：遵循国内证券习惯（与欧美相反），已在 `main.css` 注释说明。
- **不做主题切换**：课程周期内不做亮色主题，避免两套令牌的维护成本。
