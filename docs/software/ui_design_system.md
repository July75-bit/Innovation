## 2. 信息架构

只保留 **3 层**（全局导航 → 页面 → 页面内区块），不做多级菜单：

```
全局侧栏（232px）
├─ 品牌
├─ 市场 / 赛程 / 持仓 / 交易记录        ← 一级：4 个目的地
├─ 账户卡（余额 / 总资产 / 总收益）
└─ 服务状态 + 合规声明
页面
├─ 市场页：今日简报 → 赛程条 → 搜索/筛选/排序 → 选手卡片网格（主 CTA=点卡片）
├─ 详情页：行情头（价格大字）→ 价格历史 → AI 结论（主 CTA=买入）→ 交易面板
├─ 持仓页 / 流水页：只读列表（主任务=核对）
└─ 登录页：表单（主 CTA=进入市场 / 注册）
```

**主次操作**：每页只有一个主操作——市场页「点选手」、详情页「买入」、登录页「进入市场」。
其他动作（刷新、重新分析、采纳建议、退出）一律次级样式（描边/ghost）。

## 11. 纸感模式（2026-11-18，当前基线）

**背景**：用户反馈「界面太繁复，一打开就是几十项内容涌过来，没有读的欲望」，要求**可读、低密度、简洁、从容、秩序、克制**。
经确认采用三条原则：**先试点两页 → 纸感（去玻璃）→ 市场页一屏 6 张卡**。

### 11.1 设计语言
- **纸感**：暖中性底色 + 纯白卡片 + 1px 细边；不用模糊、高光、投影、渐变、悬停位移。
- **排版优先**：正文行高 1.6→**1.7**；标题 24/20/16；数字用 tabular-nums；辅助信息降到 13px 的灰。
- **层级靠留白**：区块间距 24→32/48；侧栏 232→**220**；内容最大宽 1280→**1040**（阅读行宽收窄）。
- **色彩克制**：主色只用于主操作与涨跌；选中态从「彩色底 pill」改成**深色文字 + 2px 左竖线**。

### 11.2 令牌变化（CSS 与 JSON 同步，spec 守卫）
| Token | 深色 | 浅色 | 说明 |
| --- | --- | --- | --- |
| `--color-canvas` | `#141310` | `#f6f4ef` | 暖纸底 |
| `--color-surface` | `#1b1a17` | `#ffffff` | 卡片 |
| `--color-border` | `#2e2b25` | `#e6e2d9` | 1px 细边 |
| `--line-height-body` | `1.7` | 同 | 正文更松 |
| `--layout-sidebar-width` / `--layout-content-max` | `220 / 1040` | 同 | 收窄阅读区 |

玻璃令牌不再是"半透明 + 模糊"：`liquid-glass.css` 末尾统一覆盖成实色表面（类名与降级逻辑保留，可一键回滚）。

### 11.3 五页改了什么
| 页面 | 主要变化 |

### 11.6 顶部信息条：图标替代文字（2026-11-18）

市场页顶部原先是「一句话 + 『AI 生成』+ 『展开要点』按钮」和一行
「第 18 轮 · FaZe Clan vs NAVI 比赛中，4 人暂停交易　看赛程」——按钮像个小方框、句子太长。

- 简报操作：文字按钮 → **星标图标（来源，悬停/读屏给出「AI 生成简报 / 简化模式」）+ 箭头图标（展开/收起，`aria-expanded`）**；
- 展开后的三条要点：每行「小图标 + 短标题 + 一行值」（`最该看 / 低价区 / 停牌`），轮次与对阵不再重复（比赛行已有）；摘要行用 `em` 限宽，宽屏一行放得下；
- 比赛行：长句 → **轮次 + 两队队标与队名 + 圈形暂停图标「N 人」+ 日历图标（跳赛程）**；
- 全部图标带 `aria-label` / `sr-only` 文案，点击区 ≥40px；移动端整行仍是一行、无横向溢出。

证据：`107~109-market-top-icons-*.png`。

### 11.7 重点数字条：用大小与颜色取代句子（2026-11-18）

用户反馈：简报那一行「太短、换行太早、字太多、没有重点」，要求用大小/颜色突出涨跌、用符号取代文字。

- 后端 `_brief_items` 增补结构化字段：`kind`（up/low/halt）、`name`、`value`、`sub`、`tone`；
  原 `title/detail` 保留（旧前端与测试兼容）。
- 前端市场页：有结构化字段时渲染**重点数字条**——三组「图标 + 名字 + 大号数字 + 小字补充」：
  - 涨跌值 24px/600，**涨红跌绿**（`+13.96%` 用 `--up-text`，负值用 `--down`）
  - 低价与停牌用 20px；停牌用琥珀色 `--halt`
  - 一行 `nowrap`（≥900px），窄屏自动两行；不再有长句
- AI 原话（`summary`）默认不显示，展开时才以灰色小字出现 + 停牌名单，避免「字太多」。
- 旧数据/测试 mock 不含结构化字段时，自动回退到「一句话 + 箭头」的旧样式（渐进升级）。

证据：`113~116-highlights-*.png`。

### 11.8 返回保留状态 + 默认排序（2026-11-18）

用户反馈：点开选手再退出来，市场的排序/筛选就回到默认了；并问「排序真的该默认列表顺序吗」。

- **状态记忆**（`composables/useMarketState.ts`，`sessionStorage` 按标签页）：
  - 市场页记住：排序、交易状态筛选、搜索词、简报展开状态、**滚动位置**；
  - 进入选手详情/赛程后再回来，组件重新挂载即可还原；刷新页面同样保留；坏数据/隐私模式自动退回默认。
  - 滚动位置在 `onBeforeUnmount` 记录、数据加载完一帧后用 `requestAnimationFrame` 还原（否者卡片没渲染够高滚不过去）。
- **赛程页**记住上次浏览的轮次（`playerstock.schedule.round.v1`），返回时接着看，而不是跳回今天。
- **默认排序换成「涨幅从高到低」**：打开先看今天谁在动，比按 id 的「列表顺序」更像行情页；
  下拉里保留「列表顺序」一项，需要原始顺序仍可切回。

证据：`117-market-state-restored.png`、`118-schedule-round-restored.png`。

### 11.9 动效：短、只动 opacity/transform、尊重减少动效（2026-11-18）

目标：切换页面、开菜单、进下一层时有"丝滑"反馈，但不抢注意力。

| 场景 | 做法 | 时长 |
| --- | --- | --- |
| 路由切换 | 旧页淡出 → 新页淡入 + 上移 8px（`mode="out-in"`，不重叠） | 120ms + 240ms |
| 移动端抽屉 | `translateX(-105%) → 0`，`cubic-bezier(.22,1,.36,1)` | 260ms |
| 抽屉遮罩 | opacity 0 → 0.55（`fade` 过渡） | 200ms |
| 弹窗 | 遮罩淡入 + 面板上移 10px、scale .985 → 1 | 180–220ms |
| 下拉弹层 | opacity + `translateY(-4px)`、scale .99 → 1，原点在顶部 | 140–160ms |
| 市场卡片 | opacity + 上浮 4px，20ms 阶梯（最多 120ms 延迟） | 300ms |
| 登录页 | 淡入 + 上移 6px（它不走 RouterView 过渡） | 240ms |
| hover / 选中 | 颜色/背景/边框过渡 | 120–160ms |

- 全部只用 `opacity` / `transform`，不触发布局；`mode="out-in"` 避免两页同时在场。
- **`prefers-reduced-motion: reduce` 全部退化为瞬时**：路由/遮罩/弹窗/下拉/卡片/抽屉/登录页均不播动画。

验证（CDP 逐帧采样，非目测）：路由 leave 透明度 1→0.017（8 帧）、enter 位移 7.64px→0.75px；
抽屉中段 `translateX(-160px)` + 遮罩 opacity 0.07；弹窗遮罩 0→0.26→0.76→0.997；下拉 0.88→1；
开启减少动效后 `document.getAnimations()` 为空、抽屉 `transition-duration: 0s`。

### 11.10 专业化打磨：品牌、元信息与细节（2026-11-18）

目标：让作品从"能用的课程 demo"更像"正经产品"。

- **品牌资产**：生成红色圆角方块 + 白色 P 的 SVG/ICO/PNG 图标（`favicon.svg`/`favicon.ico`/`icon-192/512.png`/`apple-touch-icon.png`），

### 11.12 深色适配的根因：`color-scheme`（2026-11-19）

用户反馈：夜间模式下市场页「排序方式」下拉仍是白底。**根因不在某个组件的颜色**，而是全站从未声明
CSS `color-scheme`——原生表单控件（`<select>` 弹层、日期选择器、滚动条、自动填充）按它决定配色，
不读我们的 CSS 变量。所以哪怕把 `select` 本身写成透明背景，浏览器弹出的选项列表仍是白的。

修法（第一性原理：让平台知道"这是深色页面"）：

```css
:root { color-scheme: dark; }
[data-theme='light'] { color-scheme: light; }
```

配套：
- 市场排序下拉显式 `appearance: none` + 自绘箭头 + `option { background: var(--color-surface) }`，
  系统弹层与自绘外观都跟主题走；
- 浏览器自动填充（`input:-webkit-autofill`）用 `box-shadow inset` 强制回主题底色，避免深色下刷成浅黄；
- 主按钮/买卖按钮上的白字统一 `--color-action-text`；队标底板固定浅色（黑/白队标才看得清），边框改深色细边。

**防回归规则**（`src/__tests__/theme-guards.spec.ts`）：
1. 深浅两套主题必须声明 `color-scheme`；
2. 原生 `<select>` 必须 `appearance: none` 且给 `option` 上色；
3. 样式里禁止硬编码 `#fff/#000/white/black`（白名单：令牌文件、历史玻璃规范、队标底板、UI-Kit 示例）；
4. `::selection` / autofill 适配不得被删。

证据：`125-dark-market.png`、`128-dark-auth.png`。

### 11.13 赛程 · 比赛抽屉（2026-11-19）

需求：赛程每一天的对战都能点开，看到该场选手，再进入选手市场购买界面。

- **入口**：比赛列表任意一行（含未来 28 轮，纯展示不涉及预测）——行可鼠标点、也可键盘 Enter/Space；
  打开后同步把上方轮次卡切到该轮（保留原有"点行看这一轮"的行为）。
- **形态**：右侧抽屉（`role="dialog"` + `aria-modal`），宽 `min(420px, 100vw)`，遮罩淡入、面板 260ms 滑入；
  Esc / 遮罩 / 关闭按钮都能关；打开时锁 body 滚动、焦点落到关闭按钮。
- **内容**：该场两队各 2 名选手的精简卡——队标/名字/位置/现价/涨跌（涨红跌绿）+ 交易状态；
  点卡片进 `/players/{id}` 看价格历史、AI 建议并下单（赛程页**不做交易**，避免误操作）。
- **数据**：赛程本身仍是纯静态派生；选手数据**懒加载**（点开才请求 `/api/players`，成功后缓存），
  失败给"重试"，不影响赛程浏览；看历史/未来场次不会误标"停牌"（只有当前轮次的两队才标停牌）。
- **返回路径（2026-11-19 补）**：抽屉状态与 URL 同步（`?round=N`，走 `router.replace` 不新增历史记录）；

### 11.20 移动端顶栏下滑隐藏 / 上滑出现（2026-11-21）

用户反馈：手机上向下滑内容时，顶栏不消失、只是半透明，文字会和内容叠在一起。

- **改为 fixed 覆盖层**（不再占网格行）：背景用画布实色 `--color-canvas` + 底部细边，内容从下面滚过不会透出文字
- **hide-on-scroll**：下滑超过 6px → `translateY(-100%)` 收起；上滑超过 6px → 回位；
  距顶部 <24px 一定显示（回到列表顶部不会「顶栏不见了」）；换路由强制显示
- **丝滑动画**：`transform` 240ms `cubic-bezier(0.22, 1, 0.36, 1)`；`will-change: transform`；
  `prefers-reduced-motion: reduce` 时不加动画
- 用 `requestAnimationFrame` 合并滚动事件，避免高频重排
- 内容区顶部 padding = 56px + 安全区 + 原间距，顶栏收起时内容不会被遮住；底部 4 Tab 不变

证据：`145-mobile-topbar-hidden.png`、`146-mobile-topbar-revealed.png`。
