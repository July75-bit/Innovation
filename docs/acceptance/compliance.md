## 1. 虚拟币与合规声明（必须写进 README 和答辩开场）

1. 本项目所有"货币"均为**虚拟币**，由系统凭空发放，**不可充值、不可提现、不可兑换**任何实物、服务或真实货币。
2. 本项目中的"选手股"是**娱乐性模拟交易**，与任何真实证券、期货、博彩产品无关，不构成投资建议。
3. 本项目所有选手均为**虚构角色**，名称、战队、比赛数据均由程序生成，与真实人物、真实赛事、真实俱乐部无关。
4. 本项目仅用于**课程学习与演示**，不对外提供任何形式的交易服务。
5. 演示与文档中主动声明上述定位，避免被误解为博彩或金融产品。
