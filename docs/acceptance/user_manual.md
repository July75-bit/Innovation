## 1. 这是什么

PlayerStock 是一个**虚拟选手股交易**的体验网站。

- 你拿到 5000 信用点，可以买入/卖出虚拟选手的"股票"
- 选手股的价格会随模拟比赛的表现变化
- AI 会给你"买入 / 卖出 / 持有"的建议，但**只是建议，不会替你交易**

> ⚠️ 本站所有货币均为信用点，**不能充值、不能提现、不能兑换**任何实物或货币，仅用于课程演示。

## 2.5 注册与登录（可选）

演示账户（`demo`）**不需要登录**，打开即可交易；如果你想用自己的名字留一份独立持仓：

1. 打开 `https://playerstock-frontend-mdlk.onrender.com/auth`；
2. 填用户名（3–20 位）与口令（≥8 位），点**注册**——注册成功即自动登录；
3. 之后刷新页面不用重新登录（令牌存在浏览器本地，有效期 **30 天**）；
4. 打开「我的」页 →**退出登录**可撤销令牌；如需连数据一起删，用**删除账号**（要再输一次口令）。

**安全口径**：口令在服务端用 PBKDF2-HMAC-SHA256 加盐 10 万次散列后存库，**明文口令不落库、不打日志**；
令牌是随机不透明串（不是可解析的 JWT），退出即失效。

## 4. 操作步骤

### 4.1 查看行情

1. 打开首页，看到选手列表
2. 每行显示：选手名、当前价格、涨跌幅（红色上涨 / 绿色下跌）、表现评分
3. 价格后面的百分比表示相对上一次价格的变化

### 4.2 买入

1. 点击某个选手，进入详情页
2. 在数量输入框填数量（必须是正整数，单选手最多持有 50 股）
3. 点「买入」
4. 成功：交易面板里的余额减少，持仓增加，流水新增一条
5. 失败：页面提示原因（如"余额不足，当前余额 50.00，需要 100.00"）

### 4.3 卖出

1. 进入选手详情页或持仓页
2. 填数量，点「卖出」
3. 只能卖出你持有的数量，不能卖空
4. 成功后余额增加，持仓减少

### 4.4 查看 AI 建议

1. 进入任意选手详情页
2. 页面打开后 AI 会自动分析，几秒后出现建议卡（想要新结果可以点「重新分析」）：

| 元素 | 含义 |
| --- | --- |
| 买入 | 建议买入 |
| 卖出 | 建议卖出 |
| 持有 | 建议继续持有 / 观望 |
| 理由 | 为什么给出这个建议（会引用具体价格和评分） |
| 风险 | 低 / 中 / 高 |

> AI 不可用时仍会给出"规则版建议"，页面会标注来源，交易功能不受影响。

### 4.5 查看持仓与收益

1. 点左侧导航「持仓」
2. 看到：持有数量、买入均价、当前价格、市值、浮动盈亏
3. 盈亏为正显示红色，为负显示绿色

## 5. 常见问题

| 问题 | 回答 |
| --- | --- |
| 我的信用点能换钱吗？ | 不能。信用点不可充值、不可提现、不可兑换。 |
| 为什么价格突然变了？ | 模拟比赛结果触发了价格更新，详情页会写明变化原因。 |
| 为什么买不了某个选手？ | 可能原因：余额不足、超过 50 股上限、**该选手所在战队正在比赛**（整队暂停交易，队友也一样买不了）。 |
| AI 说的准吗？ | 不保证。AI 只根据历史数据给建议，不构成投资建议。 |
| 刷新后数据没了？ | 首页数据会重新加载；如果交易记录消失，请把情况反馈给演示者。 |
| 手机上能用吗？ | 能。手机上用底部标签切换页面，排版已适配常见手机宽度；演示仍以电脑为主。 |

## 6. 演示流程脚本（答辩用）

> 时间分配：介绍 8 分钟 + 演示 2 分钟 + 问答 5 分钟

1. **开场声明**（10 秒）：信用点、不可兑换、纯娱乐
2. 打开市场页 → 说明"**16 名**虚拟选手、8 支战队各 2 人，价格随比赛表现变化"
3. 搜索并点进 ZywOo → 指着折线图说明"每一次上涨都有原因"
4. **拆解一次价格变化** → 指着某个价格点，念出它的涨跌幅、本轮得分和 S
5. 买入 2 股 → 余额、持仓、流水三处同时变化
6. 指 AI 建议卡 → 展示建议 + 理由 + 风险等级
7. （加分）断开 AI → 再点一次，展示规则版兜底，说明"AI 挂了也能交易"
8. 打开持仓页 → 展示浮动盈亏
9. 收尾：讲架构（确定性骨架 + 智能体肌肉）

## 7. 反馈与已知问题

| 已知问题 | 说明 |
| --- | --- |
| 首次打开很慢 / 先出现加载页 | 免费实例 15 分钟无流量会休眠，冷启动约 1 分钟；等一会儿刷新即可，不是故障 |
| 页面数据不是初始状态 | 公共演示账户谁都能用，会留下别人的交易；想要干净账户，可以在「持仓」页点「重建余额」，或注册自己的账号 |
| AI 建议显示"规则兜底" | 大模型暂时不可用（超时或服务异常），属**设计内的降级**，建议照常可用，不影响交易 |
| 数据库有效期 | Render 免费 Postgres 有到期时间，到期后需要换库或续期 |
