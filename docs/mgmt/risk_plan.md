## 2. 前三个高风险的具体预案

### R01 数据丢失（最容易被老师抓的点）

- **演示前必做**：线上买一笔 → 重启/重新部署后端 → 刷新页面看数据是否还在
- 兜底话术：如果只能用免费临时盘，主动说明"这是已知限制，方案对比见 deployment.md"，把劣势转成工程思考的加分项

### R02 集成失败

- 第 3 天设为**硬卡点**：当天没打通"查行情 → 买入 → 看持仓 → 卖出"，立刻砍掉图表、AI、排行榜，优先保闭环
- 每天 20:30 验收会只认"看得见的结果"，不接受"我写了很多代码"

### R13 最后一天改功能

- 第 5 天 24:00 起**功能冻结**
- 第 6 天只允许：修崩溃、修错别字、调演示数据、补文档
