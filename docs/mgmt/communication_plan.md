# 沟通管理计划

> **负责人**：D ｜ **截止**：第 1 天 ｜ **状态**：✅ 已填写
> **对应课程指标**：#15 项目计划、#16 协作工具、#17 团队分工、#18 技术沟通

## 1. 团队与角色

| 成员 | 角色 | 主责模块 | 对外接口人 |
| --- | --- | --- | --- |
| A | 前端负责人 | Vue 3 页面、图表、AI 展示 | 消费 B 的接口 |
| B | 后端与交易系统 | API、交易规则、数据库 | 提供接口给 A/C/D |
| C | 行情与定价 | 模拟赛事、价格算法、价格历史 | 数据给 B，原因给 A |
| D | AI / 测试 / 部署 / 文档 | AI 分析、集成测试、上线、材料 | 交付给老师 |

## 2. 会议节奏

| 会议 | 时间 | 时长 | 参与人 | 产出 |
| --- | --- | --- | --- | --- |
| 每日站会 | 每天 09:30 | 15 分钟 | 全员 | 昨日完成 / 今日计划 / 阻塞项 |
| 晚验收会 | 每天 20:30 | 20–30 分钟 | 全员 | 对照当日验收清单逐条打勾 |
| 接口评审 | 第 1 天上午 | 60 分钟 | 全员 | `api_contract.md` 四人签字 |
| 集成联调 | 第 3 天全天 | — | A + B + C | 交易闭环跑通 |
| 部署评审 | 第 5 天下午 | 45 分钟 | 全员 | 线上地址 + 验收结果 |
| 答辩彩排 | 第 6 天 | 2 次 × 30 分钟 | 全员 | 演示脚本 |

> 站会三问（每人 60 秒，不许展开讨论）：
> 1. 昨天交付了什么**可验收**的东西？
> 2. 今天要交付什么？
> 3. 有没有阻塞，需要谁配合？

## 3. 沟通渠道与响应约定

| 用途 | 渠道 | 响应时限 |
| --- | --- | --- |
| 日常同步、临时问题 | 微信群/QQ群 | 工作时间 30 分钟内 |
| 代码评审、接口变更 | GitHub PR / Issue | 4 小时内 |
| 阻塞升级 | 群里 @ 对应负责人 + 当面说 | 30 分钟内 |
| 文档共写 | 仓库 `docs/`，**不在聊天里传文件** | — |

**一条硬规矩**：所有结论落到仓库里（文档、代码、Issue），聊天记录不算交付物。

## 4. 分支与合并约定

| 分支 | 用途 |
| --- | --- |
| `main` | 随时可运行、可部署；CI 必须绿 |
| `feat/a-frontend`<br/>`feat/b-backend`<br/>`feat/c-pricing`<br/>`feat/d-ai-deploy` | 各人日常开发 |

合并规则：

1. 每天至少合并一次到 `main`（避免最后一天大爆炸）
2. 合并前必须 `git pull --rebase` 且本地能跑
3. PR 必须填 `.github/pull_request_template.md`
4. 改接口的 PR 必须有对接人 approve
5. **不允许**直接 push 到 `main`

## 5. 文件/目录的写权限边界（防四个 AI 互相覆盖）

| 目录 | 唯一写入人 | 其他人只能 |
| --- | --- | --- |
| `code/frontend/` | A | 读 |
| `code/backend/app/api`、`models`、`schemas`、`core` | B | 读 |
| `code/core_engine/` | C | 读 |
| `code/backend/ai/` | D | 读 |
| `docs/algorithm/pricing_model.md` | C | 提意见 |
| `docs/algorithm/ai_agent_prompt.md`、`backtest_report.md` | D | 提意见 |
| `docs/software/api_contract.md` | B | 提变更申请 |
| `docs/software/deployment.md`、`docs/mgmt/`、`docs/acceptance/` | D | 补本模块章节 |
| `tests/` | 各模块作者写自己模块的用例，D 汇总集成用例 | — |

> 这条对应分工文档的提醒："避免四个 AI 同时修改同一个文件"。给 AI 下指令时也要声明"不要修改 xx 目录"。

## 6. 升级路径（卡住了怎么办）

| 情况 | 第一步 | 第二步 |
| --- | --- | --- |
| 接口字段对不上 | 直接找 B，改 `api_contract.md` | 4 小时没解决 → 全员 15 分钟对齐 |
| 环境跑不起来 | 自己按 README 重来一遍 | 仍不行 → 找 D 远程协助 |
| 进度落后半天以上 | 砍功能（保留交易闭环 + AI 分析） | 站会宣布，同步调整当日验收项 |
| 两人改了同一文件冲突 | 以模块 owner 为准 | 冲突大就在 PR 里一起改 |
