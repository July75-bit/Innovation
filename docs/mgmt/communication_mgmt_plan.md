# 沟通管理计划

> 团队：倪颢容(A)·前端 / 胡德昊(B)·后端 / 刘宏(C)·定价 / 王泽棠(D)·AI·测试·部署·协调人｜周期：6 天
> 课程指标：#15 项目计划、#16 协作工具与风险监控、#17 团队分工、#18 技术沟通。
> 数据与合规口径：选手姓名/战队/位置为公开信息，价格与评分为项目模拟数据；非官方课程作品。
> 风险登记与应对见 [risk_mgmt_plan.md](risk_mgmt_plan.md)。

## 1. 目标与原则

- 清楚别人在做什么、我依赖谁、我有什么困难
- 所有约定有书面记录，只有一个事实来源（口头约定 24h 内落实文档）
- 问题 24h 内解决，不堆积到 第 3 天 集成日和 第 5 天 上线日
- 异步优先（Issue/PR），阻塞同步（群 @ / 拉会）

## 3. 沟通工具

| 信息类型 | 位置 | 规则 |
| --- | --- | --- |
| 需求/设计 | `docs/requirements/` | 事实来源 |

## 4. 会议制度

| 会议 | 时间 | 时长 | 产出 |
| --- | --- | --- | --- |
| 每日站会 | 08:30 | ≤15min | 三问（昨日交付/今日目标/阻塞），问题记 Issue |
| 每日验收会 | 19:30 | 20–30min | 对照验收清单 + 风险复看 → 纪要、次日目标 |
| 接口评审 | 第 1 天 | 60min | 冻结 `api_contract.md` |

| 部署评审 | 第 5 天 | 45min | 线上验收 |
| 答辩排练 | 第 6 天 | 2×30min | 演示脚本 + 计时 |

**每日验收清单：**

| 天 | 验收项 |
| --- | --- |
| 第 1 天 | 环境可运行；前端连上 `/api/health`；接口冻结 |
| 第 2 天 | 页面可看；交易接口可测；定价脚本可跑；AI 原型输出建议 |
| 第 3 天 | 买卖闭环跑通；余额/持仓/流水同步；价格历史可查；重启数据仍在 |
| 第 4 天 | 折线图+涨跌原因；AI 建议卡；异常测试通过；部署准备完成 |
| 第 5 天 | 线上可访问；买卖/查询/AI 各演示一次；持久化验证 |
| 第 6 天 | 回归测试；文档齐全；PPT；排练≥2次；代码冻结无新 feat PR |

## 5. 接口变更流程

1. **提出**：建 Issue（label: `api-change`），写明原因、影响范围、建议方案
2. **评审**：受影响方 **4h 内**评论确认（超时视为同意）
3. **批准**：协调人修订 `api_contract.md`，群内通告版本号
4. **执行**：批准后才改代码；未经流程单方面改字段按 bug 处理

## 6. 响应承诺（SLA）

| 场景 | 时限 | 升级 |
| --- | --- | --- |
| 群 @ 某人 | 工作时段(08:00–20:00) 2h | 协调人介入 |
| PR 评审 | 6h（阻塞集成的 4h） | 协调人催办 |
| 接口变更评论 | 4h | 超时视为同意 |
| 阻塞问题 | 站会立即提出 | 当天调配或砍范围 |
| 线上故障 | 5min 通报 | 协调人通报影响面 |

## 7. 冲突与升级

- 技术分歧：对照契约/验收清单讨论 30min → 无结论由协调人裁决并记录
- 组内 24h 未解决或涉及外部：提 Issue 联系教师
- 成员失联 ≥4h：群@ + 私聊 → 电话 → 启动备份人接管

## 8. 代码协作约定

| 分支 | 用途 | 规则 |
| --- | --- | --- |
| `main` | 可部署 | 只接受 develop 合并，CI 必须绿 |
| `develop` | 日常集成 | PR 需 ≥1 非作者 approve |
| `feat/*` / `fix/*` | 开发/修复 | 完成后 PR 到 develop |

- 每天至少合并一次到 develop
- 合并前 `git pull --rebase` 且本地能跑
- 不允许直接 push main
- 目录写权限见下方 §8.1 表

### 8.1 文件 / 目录写权限边界

> 防止多人（或多个 AI 辅助工具）同时修改同一文件导致冲突。仓库已按课程模板迁移为 `code/` 结构。

| 目录 / 文件 | 唯一写入人 | 其他人权限 |
| --- | --- | --- |
| `code/frontend/` | 倪颢容（A） | 只读 + PR 评论 |
| `code/backend/app/api`、`models`、`schemas`、`core` | 胡德昊（B） | 只读 + PR 评论 |
| `code/core_engine/` | 刘宏（C） | 只读 + PR 评论 |
