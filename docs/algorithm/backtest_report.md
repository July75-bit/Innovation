## 1. 回测目标

## 2. 策略定义

| 策略 | 定义 | 说明 |
| --- | --- | --- |
| **S1 智能体策略** | 按 AI 的 BUY/SELL/HOLD 建议操作（HOLD 不动） | 待评测对象 |
| **S2 随机策略** | 每轮随机买入/卖出 1 股 | 基线：证明不是运气 |
| **S3 持有策略** | 开局等权买入，之后不再操作 | 基线：证明不是靠大盘 |
| **S4 规则版策略** | 用 `rule_fallback` 的阈值规则操作 | 证明 LLM 相对规则有增量价值 |
