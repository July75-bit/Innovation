# 用户故事地图与 INVEST 验收标准

> **负责人**：D 牵头，A 补前端视角故事 ｜ **截止**：第 1 天结束 ｜ **状态**：⬜ 待填写
> **对应课程指标**：#1 用户故事、#2 需求聚焦

## 1. 角色（Persona）

| 角色 | 描述 | 关注点 |
| --- | --- | --- |
| 交易新手 | 第一次打开网站，不懂定价 | 我要知道"现在该不该买" |
| 行情玩家 | 关注某几位选手，频繁看价格 | 我要看到价格曲线和涨跌原因 |
| 演示者（答辩时的你） | 要在老师面前稳定演示 | 我要数据可复现、按钮都有用 |

## 2. 用户故事地图（按活动阶段）

```
浏览行情 ──► 研究选手 ──► 决定交易 ──► 持有观察 ──► 复盘收益
   │            │            │            │            │
 看列表       看折线图      买入/卖出     看持仓       看流水
 看涨跌       看AI建议      确认余额      看估值       算盈亏
 看评分       看涨跌原因    看错误提示    看风险等级   看历史价格
```

## 3. 用户故事清单（INVEST）

> 每条必须满足：Independent / Negotiable / Valuable / Estimable / Small / Testable。
> 验收标准统一用 Given-When-Then 写。

### 故事 1：浏览市场行情

- **As a** 交易新手 **I want** 打开首页就看到所有选手的当前价格和涨跌幅 **so that** 我能快速找到关注目标
- **AC1**：Given 后端有 8 名选手，When 打开首页，Then 列表显示 8 行，每行含名称、当前价（2 位小数）、涨跌幅（带正负号与颜色）、表现评分
- **AC2**：Given 后端不可用，When 打开首页，Then 显示"行情加载失败"而不是空白页
- **验收人**：A ｜ **状态**：⬜

### 故事 2：查看选手详情与涨跌原因

- **As a** 行情玩家 **I want** 看到某选手的价格历史曲线和最近一次变化原因 **so that** 我能理解价格为什么动
- **AC1**：Given 该选手有 ≥10 条价格历史，When 打开详情页，Then 渲染折线图且横轴为时间升序
- **AC2**：Given 最近一次更新原因是"模拟比赛表现提升"，When 打开详情页，Then 页面展示该原因文案
- **验收人**：A + C ｜ **状态**：⬜

### 故事 3：买入选手股

- **As a** 行情玩家 **I want** 输入数量后一键买入 **so that** 我能押注我看好的选手
- **AC1**：Given 余额 5000、选手价 100、买入 2 股，When 提交，Then 余额变 4800、持仓 +2、流水新增 1 条 BUY
- **AC2**：Given 余额 50、选手价 100、买入 1 股，When 提交，Then 提示"余额不足"，且余额/持仓/流水都不变
- **AC3**：Given 持仓已达 50 股，When 再买入 1 股，Then 提示"超出单选手持仓上限"
- **验收人**：A + B ｜ **状态**：⬜

### 故事 4：卖出选手股

- **As a** 行情玩家 **I want** 卖出我持有的股票 **so that** 我能止盈止损
- **AC1**：Given 持有 3 股，When 卖出 1 股，Then 持仓变 2 股、余额增加（按最新价）、流水新增 1 条 SELL
- **AC2**：Given 持有 0 股，When 卖出 1 股，Then 提示"持仓不足"且不产生负持仓
- **AC3**：Given 选手处于比赛暂停状态，When 提交买/卖，Then 提示"该选手暂停交易"
- **验收人**：A + B ｜ **状态**：⬜

### 故事 5：查看持仓与收益

- **As a** 行情玩家 **I want** 看到我的持仓数量和浮盈浮亏 **so that** 我知道现在赚没赚
- **AC1**：Given 持有 2 股、均价 98、当前价 103.5，When 打开持仓页，Then 显示市值 207.00、浮盈 11.00（+5.61%）
- **AC2**：Given 持仓为 0，When 打开持仓页，Then 显示空状态提示，不显示 0 股行
- **验收人**：A + B ｜ **状态**：⬜

### 故事 6：获取 AI 交易建议

- **As a** 交易新手 **I want** 让 AI 告诉我该买还是该卖，并说明理由 **so that** 我不用自己啃数据
- **AC1**：Given 任意有效选手，When 点击"AI 分析"，Then 返回 BUY/SELL/HOLD 之一 + 理由 + 风险等级（LOW/MEDIUM/HIGH）
- **AC2**：Given 未配置 LLM 密钥，When 点击"AI 分析"，Then 仍返回合法结构，且 `source = "rule_fallback"`
- **AC3**：Given 模型返回非 JSON 文本，When 前端请求分析，Then 接口不 500，返回兜底建议
- **验收人**：A + D ｜ **状态**：⬜

### 故事 7：查看交易流水

- **As a** 行情玩家 **I want** 看到每笔买卖的时间和价格 **so that** 我能复盘我的操作
- **AC1**：Given 有 3 笔交易，When 打开流水页，Then 按时间倒序显示，每行含方向、数量、成交价、时间
- **验收人**：A + B ｜ **状态**：⬜

## 4. 故事优先级（MoSCoW）

| 优先级 | 故事 | 理由 |
| --- | --- | --- |
| Must | 1、3、4、6 | 交易闭环 + AI 亮点，缺一个答辩就崩 |
| Should | 2、5、7 | 完整体验，第 4 天完成 |
| Could | 排行榜、签到、净值曲线 | 有余力再加 |
| Won't | 真实数据接入、多智能体、区块链 | 6 天版明确不做 |
