## 页面要素清单（画的时候对照）

### 市场页 `/`
- 顶部导航：Logo / 市场 / 持仓 / 流水 / 账户余额
- 选手表格：名称、当前价、涨跌幅（正绿负红）、表现评分、操作按钮

### 选手详情页 `/players/:id`
- 价格大字 + 涨跌幅
- 历史价格折线图
- 最近一次价格变化原因
- AI 建议卡：action 徽标（BUY/SELL/HOLD）+ 理由 + 风险等级 + "仅为建议"免责提示
- 交易区：数量输入 + 买入 / 卖出

### 持仓页 `/positions`
- 总市值 / 总浮盈
- 持仓表：选手、数量、均价、当前价、市值、浮盈

### 交易记录页 `/trades`
- 时间倒序流水表：时间、选手、方向、数量、成交价、金额

## 空状态与异常状态（必须有）

| 状态 | 表现 |
| --- | --- |
| 加载中 | 骨架屏或 loading 文案 |
| 无数据 | "暂无可交易选手""还没有持仓""还没有交易记录" |
| 请求失败 | "加载失败，点击重试" + 错误原因 |
